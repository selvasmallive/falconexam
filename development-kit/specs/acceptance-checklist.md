# Global Acceptance Checklist

A milestone is not complete unless:

- Code builds from a clean checkout.
- Automated tests pass.
- Database migrations apply and rollback strategy is documented.
- Authorization and tenant isolation are tested.
- No secrets or private media URLs are exposed.
- Audit events are generated for sensitive actions.
- Accessibility impact is reviewed.
- Privacy/data-flow impact is documented.
- Threat model is updated for new attack surfaces.
- User-facing limitations are documented honestly.
- AI output remains advisory and human-reviewed.
- `docs/STATUS.md`, `docs/DECISIONS.md` and `docs/KNOWN_LIMITATIONS.md` are updated.
